This project is part of Round 1 selection task for an internship opportunity at NeuroNexus Innovations. The objective was to design a Google Form-style webpage using only HTML and CSS, inspired by the theme and design aesthetics of the NeuroNexus website.

📌 Task Objective
Create a visually appealing and functional custom form using:

✅ Pure HTML & CSS (no frameworks or JS)

✅ A design that reflects the branding and color theme of NeuroNexus

✅ Neat and organized code structure suitable for frontend development roles

🎨 Features
Elegant white form layout with blue border accents, matching the NeuroNexus branding

Responsive and clean UI designed to mimic a form submission page

Custom fonts and background setup for a professional appearance

Simple yet effective styling to demonstrate HTML/CSS proficiency
